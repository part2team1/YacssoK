# 외부 소프트웨어와 자료 출처

## Ultralytics

이 앱의 알약 탐지는 Ultralytics Python 패키지를 사용합니다.
설치 버전은 `uv.lock`에 기록되어 있습니다.

- 프로젝트: https://github.com/ultralytics/ultralytics
- 저작권·라이선스: Ultralytics 패키지가 제공하는 AGPL-3.0 고지를 따릅니다.
- 패키지에 포함된 라이선스 원문: `docs/licenses/Ultralytics-AGPL-3.0.txt`
- 라이선스 안내: https://www.ultralytics.com/license

이 파일은 외부 소프트웨어의 고지이며, 의약품 사진이나 학습 원본의
이용 조건을 소프트웨어 라이선스로 바꾸지 않습니다.

## 의약품 정보와 공식 식별사진

식약처 의약품안전나라와 공공데이터포털의 제품정보·식별사진 조회 자료를
사용합니다. 각 알약 카드에 품목별 공식 출처 링크를 표시합니다.
조회 자료는 저장된 시점의 정보이며, 실제 최신 허가 상태와 다를 수 있습니다.

## 학습 원본 사진

공개용 파일에는 AI Hub·대회 학습 원본 사진과 그 사진의 예측 표시본을
포함하지 않습니다. 화면의 촬영 안내는 사진이 아닌 코드로 그린 도식입니다.
