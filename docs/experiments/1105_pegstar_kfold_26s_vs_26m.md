# 1105 · 조합 단위 K-fold: YOLO26s vs YOLO26m (v3allcp, D12)

Nov 5, 2026 · pegstar · 절차는 [조합 단위 K-fold 가이드](../guides/04_grouped_kfold.md)

## 결론

- **같은 fold에서 26s 0.9428 ± 0.0126, 26m 0.9397 ± 0.0216.** fold별 차이(26s − 26m) 평균 **+0.003 ± 0.017**, 26s가 5개 중 3개 fold에서 높음 → **성능은 사실상 같다**(차이가 표준편차보다 훨씬 작음).
- **26s는 학습이 2배 빠르고(fold당 33분 vs 69분) fold 간 흔들림도 작다.** 성능이 같으므로 26s를 고를 근거는 속도·안정성이다.
- **데이터 효과가 모델 차이보다 훨씬 크다.** 같은 26m에서 v0+RFS 0.860 → v3allcp 0.940 (약 +0.08). 다만 분할(v0_f vs v1_f)과 라벨(v0 vs 정제 v1)이 함께 바뀌어 데이터만의 효과로 단정할 수는 없다.
- **OCR 재분류(26m 5개 fold)는 변화 없음**(변화량 평균 0.0000).

## 조건

| 항목 | 값 |
| --- | --- |
| 데이터 | v3allcp = 정제 v1 + AI Hub(TL_1·TS_1, 새 클래스 포함) + copy-paste 합성, RFS 0.1 |
| 분할 | `v1_f0~4` (대회 이미지만 조합 단위, `kfold_split.py`), AI Hub는 fold train에만(`make_ext_folds.py`) |
| 합성 | fold마다 그 fold train으로 새로 생성(`run_kfold_synth.py`), 두 모델이 같은 합성 사용 |
| 학습 | 50 epoch, img 640, seed 42, 26m batch 8 / 26s batch 16 (8GB GPU) |
| 지표 | mAP@[0.75:0.95] (`metrics.json`의 `map`), 검증 fold당 44~46장 |

## 공식 검증 점수와의 차이

같은 설정을 공식 v1 검증셋(47장)으로 채점하면 26m 0.996, 26s 0.991이다. 공식 검증셋은 학습셋과 같은 알약 조합이 섞여 있어 K-fold보다 약 0.05 높다. 모델 선택은 K-fold 평균으로 한다.
