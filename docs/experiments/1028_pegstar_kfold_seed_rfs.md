# K-fold·seed·과적합·재표본화 실험 결과 (10/28)

2026-10-28 · 작성: pegstar (Model Architect A)

알약 조합 단위 5-fold로 재보니 YOLOv8m의 실제 검증 점수는 0.829 ± 0.055로, 누수가 있는 공식 분할(0.959)보다 약 0.13 낮았다. epoch 과적합은 거의 없고 문제는 새 조합에서의 약 이름 구분이며, 오버샘플링이 평균 +0.019로 가장 유망했다.

## 1. 실험 목적과 공통 조건

**요청:** K-fold와 seed를 추가해 과적합 테스트까지 연결, train/val 학습 곡선 선그래프, 재표본화 가능 여부.

| 항목 | 값 |
| --- | --- |
| 모델 | YOLOv8m (`configs/yolo_m_v8m.yaml`) |
| 학습 설정 | img 640, epoch 50, batch 8, optimizer auto, YOLO 기본 증강 |
| 데이터 | 학습 이미지 232장 (알약 조합 114개, 조합당 카메라 각도 70/75/90 등) |
| 평가 | 스켈레톤 `compute_map`, 대회 지표 mAP@\[0.75:0.95\] |
| 장비 | RTX 5060 Laptop GPU (8GB), torch 2.11.0+cu128 |

**용어**

- **K-fold**: 데이터를 5등분해 돌아가며 검증. 이번엔 같은 알약 조합의 사진이 한 fold에만 들어가도록 **조합 단위**로 나눔 (StratifiedGroupKFold)
- **재표본화**: 평가용(K-fold 자체)과 학습용(드문 알약 이미지를 더 자주 학습하는 오버샘플링) 두 가지를 모두 했다

## 2. K-fold: 조합 단위 5-fold

같은 알약 조합은 항상 한 fold에만 들어간다 (분할 스크립트가 fold마다 겹치는 조합 수를 출력하므로 0인지 확인). 실행: `scripts/kfold_split.py` → `scripts/run_kfold.py --folds 0 1 2 3 4`.

| fold | mAP@\[0.75:0.95\] | mAP75 | 학습 시간 (분) |
| --- | --- | --- | --- |
| f0 | 0.793 | 0.825 | 6.7 |
| f1 | 0.893 | 0.917 | 6.0 |
| f2 | 0.755 | 0.813 | 7.5 |
| f3 | 0.860 | 0.885 | 6.7 |
| f4 | 0.844 | 0.871 | 8.6 |
| **평균 ± 표준편차** | **0.829 ± 0.055** | 0.862 ± 0.043 |  |

- **누수 효과:** 공식 분할 v0(이미지 단위 분할)에서는 0.959였다. 조합 단위로 나누면 약 0.13 낮아진다. 차이는 검증에 학습과 거의 같은 사진(같은 조합, 각도만 다름)이 들어가 있었기 때문이다.
- **fold 간 흔들림이 크다 (0.755\~0.893).** 어제 medium 4종의 점수 차이(최대 0.019)보다 훨씬 커서, 그 비교는 분할 운일 수 있다.
- 이 점수가 실제 Kaggle 점수에 더 가까울 것으로 본다. 테스트에는 학습에 없는 클래스도 있어 더 낮을 수 있다.

## 3. seed: 같은 분할에서 3번

공식 분할 v0에서 seed만 바꿔 학습했다. 실행: `scripts/run_kfold.py --seeds 42 0 1`.

| seed | mAP@\[0.75:0.95\] | mAP75 |
| --- | --- | --- |
| 42 | 0.961 | 0.984 |
| 0 | 0.952 | 0.985 |
| 1 | 0.965 | 0.984 |
| **평균 ± 표준편차** | **0.959 ± 0.006** | 0.984 ± 0.000 |

**흔들림 비교**

| 바꾼 것 | 표준편차 | 의미 |
| --- | --- | --- |
| seed (학습 무작위성) | 0.006 | 같은 조건에서도 생기는 작은 흔들림 |
| 분할 (K-fold) | 0.055 | 검증 데이터 구성에 따른 흔들림, 약 8배 |

점수를 흔드는 건 무작위성보다 검증 데이터 구성이다. 그래서 모델·설정 비교는 seed 반복보다 **K-fold 평균(fold별 짝 비교)** 으로 해야 믿을 수 있다. 똑같은 seed(42)로 다시 돌리면 어제와 점수가 소수점까지 같아(0.9609) 재현성도 확인했다.

## 4. 과적합 테스트: 학습 곡선

실행마다 YOLO가 남기는 `results.csv`(epoch별 train/val 손실, mAP, 학습률) 8개(5-fold + seed 3개)를 분석했다. 선그래프는 `notebooks/scratch/pegstar_curves.ipynb`에서 그린다. 학습률은 train에만 있는 값이라 "train/val 선그래프"는 손실 곡선으로, 학습률은 별도 곡선으로 그렸다.

**① epoch를 많이 돌려 생기는 과적합은 거의 없다**

| 손실 | val 최저점 이후 다시 오른 정도 (8개 실행) |
| --- | --- |
| box | 0\~0.3% (끝까지 내려감) |
| dfl | 0\~0.2% |
| cls | 0\~4.7%. 3% 넘은 건 seed 42 하나뿐 (seed 0은 0.5%, seed 1은 1.8%) |

seed 42의 신호는 다른 seed에서 재현되지 않아 우연한 흔들림으로 본다. 검증 mAP는 15\~45 epoch에 최고점을 찍고 거의 유지돼(마지막과 최고점 차이 최대 0.016) 50 epoch는 적당하다.

**② 대신 처음 보는 조합에서 약 이름 구분이 약하다**

| 마지막 epoch의 val − train 차이 | cls 손실 | box 손실 |
| --- | --- | --- |
| 공식 분할 v0 (누수 있음) | 0.06 \~ 0.09 | 0.005 \~ 0.01 |
| 조합 단위 K-fold | **0.17 \~ 0.63** | 0.01 \~ 0.05 |

박스 위치는 새 조합에서도 잘 맞히지만, 약 이름 손실은 학습보다 훨씬 높게 남는다. 문제는 "오래 학습해서"가 아니라 **처음 보는 조합에서의 일반화**다. 누수가 있는 v0에서는 이 차이가 가려져 보이지 않았다.

참고: YOLO는 마지막 10 epoch에 모자이크 증강을 끄므로, 그 구간에 train 손실이 갑자기 떨어지는 것만으로 과적합이라고 판단하지 않았다.

## 5. 재표본화: 오버샘플링

드문 알약이 든 이미지를 학습 목록에 여러 번 넣는 Repeat Factor Sampling(`data.repeat_threshold: 0.1`, 설정 `configs/yolo_m_v8m_rfs.yaml`)을 같은 5-fold로 비교했다. 학습 이미지의 10%보다 드물게 나오는 알약부터 반복된다. fold마다 점수 차이가 커서 평균만이 아니라 **같은 fold끼리 짝지어** 비교했다.

| fold | 기본 | 오버샘플링 | 차이 |
| --- | --- | --- | --- |
| f0 | 0.793 | 0.797 | +0.004 |
| f1 | 0.893 | 0.917 | +0.024 |
| f2 | 0.755 | 0.823 | **+0.068** |
| f3 | 0.860 | 0.835 | −0.024 |
| f4 | 0.844 | 0.868 | +0.024 |
| **평균** | **0.829 ± 0.055** | **0.848 ± 0.046** | **+0.019** |

- 5개 fold 중 4개에서 올랐고, mAP75도 0.862 → 0.873으로 올랐다.
- 가장 어려웠던 f2에서 가장 크게 올랐고, fold 간 편차도 0.055 → 0.046으로 줄었다.
- 다만 f3에서는 내려갔고, fold별 차이가 −0.024\~+0.068로 들쓥날쓥해 통계적으로 확정하기는 어렵다 (fold 5개 짝 t검정 p ≈ 0.3).
- seed 흔들림(0.006)보다 큰 개선이 3개 fold에서 나왔다. 현재까지 시도 중 가장 유망하다.

## 6. 부수 발견 (팀 공유)

**① config의 학습률이 적용되지 않는다**

`optimizer: auto`일 때 Ultralytics는 config의 `lr`(0.01)을 무시하고 학습률을 스스로 정한다. YOLOv8m 기록의 실제 최대 학습률은 **0.000158**이었다. 학습률 실험(T1)을 하려면 `optimizer`를 `SGD`나 `AdamW`로 명시해야 한다.

**② 공식 분할 v0에도 누수가 그대로 있다**

공식 v0로 seed 42 학습한 점수가 어제 내 PC 예비 분할 결과와 소수점까지 같았다(0.9609). 같은 스크립트(`split_data.py`)와 같은 seed(42)로 만들어 **동일한 분할**이고, 검증 47장 중 34장이 학습과 같은 알약 조합이다. `split_data.py`는 이미지 단위로 나누기 때문이다. 데이터 B에게 조합 단위 재분할 검토를 요청한다 (`scripts/kfold_split.py`의 조합 단위 분할 코드 참고).

## 7. 결론과 실험 방향

**결론**

- v0 검증 점수(0.959)는 누수로 약 0.13 부풀려져 있다. 실제 일반화 성능은 조합 단위 5-fold 기준 **0.829 ± 0.055**로 본다.
- fold 간 편차가 seed 간 편차의 약 8배다. 모델·설정 비교는 seed 반복이 아니라 **같은 fold끼리 짝지은 K-fold**로 한다.
- epoch 과적합은 없다. 문제는 처음 보는 조합에서 **알약 이름(cls) 분류의 일반화**다.
- 재표본화(RFS 0.1)는 평균 +0.019(5개 fold 중 4개 개선)로 유망하지만 p ≈ 0.3이라 아직 확정은 아니다.

**우선순위**

| 순위 | 실험 | 이유 |
| --- | --- | --- |
| 높음 | 재표본화 임계값 0.05 / 0.2 | 0.1에서 개선 경향, 최적값 확인 |
| 높음 | 색상 증강 (hsv) | cls gap이 핵심 문제, 색이 알약 구분 단서 |
| 높음 | img 1024 | 각인 글자 판독으로 cls 개선 기대 |
| 낮음 | M3 box gain | box loss gap이 0.01–0.05로 작음 |
| 낮음 | epoch 늘리기 | 마지막 epoch이 최고점과 0.016 이내 |

## 8. 만든 파일과 재현 명령

| 파일 | 역할 |
| --- | --- |
| `scripts/kfold_split.py` | 조합 단위 StratifiedGroupKFold 분할 → `data/splits/v0_f0~f4` |
| `scripts/run_kfold.py` | fold·seed 반복 학습, `outputs/kfold/*_summary.csv`에 평균 ± 표준편차 |
| `notebooks/scratch/pegstar_curves.ipynb` | train/val 손실·mAP·학습률 선그래프, 과적합 판정, fold별 점수 |
| `configs/yolo_m_v8m_rfs.yaml` | 재표본화 실험 설정 (repeat\_threshold 0.1) |

```
uv run python scripts/kfold_split.py --k 5
uv run python scripts/run_kfold.py --config configs/yolo_m_v8m.yaml --folds 0 1 2 3 4 --tag kfold
uv run python scripts/run_kfold.py --config configs/yolo_m_v8m.yaml --seeds 42 0 1 --tag seed
uv run python scripts/run_kfold.py --config configs/yolo_m_v8m_rfs.yaml --folds 0 1 2 3 4 --tag kfold
```

`data/splits/v0_f*`, `outputs/`, `reports/figures/`는 커밋하지 않는다. 분할은 위 명령으로 누구나 같은 결과를 재현할 수 있다.
