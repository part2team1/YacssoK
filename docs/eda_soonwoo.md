# 순우 EDA 보강본

`notebooks/01_eda_soonwoo.ipynb`는 기존 EDA를 보강한 개인 노트북입니다. 공용 `01_eda.ipynb`와 기존 분석 함수는 유지합니다.

## 실행

1. 대회 원본을 `configs/base.yaml`의 `data.train_images`, `data.train_annotations`, `data.test_images` 경로에 준비합니다.
2. `data/annotations/manual_fix.csv`는 저장소의 팀 교정표를 사용합니다.
3. `uv sync` 후 `uv run jupyter lab notebooks/01_eda_soonwoo.ipynb`에서 위에서부터 실행합니다.

개인 노트북은 `configs/eda_soonwoo.yaml`을 읽습니다. 사진 대조는 로컬 원본과 교정표로 생성하므로 별도의 이미지 파일이나 비공개 감사 JSON을 내려받을 필요가 없습니다. 생성한 그림과 노트북 실행 출력은 공개 저장소에 올리지 않습니다.

## 추가한 데이터 점검

- 8.1: 종류 교정 3건의 문제 영역·기존 이름 참고 사진·교정 이름 참고 사진을 비교합니다.
- 8.2: 누락 박스 추가 4건의 전후 사진을 그립니다. 초록은 기존 박스, 주황은 추가 박스입니다.
- 원본 EDA의 누락 후보 8장 전체를 해결했다는 의미는 아닙니다.
- 사진과 교정표의 정합성을 점검하며 실제 약품 감정으로 해석하지 않습니다.

## 별도 부록: 모델 재평가

집계 기록은 `docs/eda_soonwoo_reevaluation.json`에 있습니다. 같은 검증 사진 47장과 저장 예측을 유지하고 팀 수동 교정만 적용했습니다. 정답 박스는 153개에서 157개가 됐습니다. 교정 전 점수가 원래 기록과 재현되는지 먼저 확인했습니다.

| 조건 | 교정 전 mAP@[0.75:0.95] | 교정 후 |
|---|---:|---:|
| D1 | 0.96903 | 0.98341 |
| D1+증강 | 0.93817 | 0.95234 |

D3 실행에는 RFS가 유지됐으므로 D1+증강으로 구분합니다. 이미지 삭제·자동 정제를 포함한 전체 v1 평가, 재학습 또는 Kaggle 점수와는 다릅니다. 노트북은 검증된 집계 기록을 표시하며 모델을 학습하거나 새로 평가하지 않습니다.
